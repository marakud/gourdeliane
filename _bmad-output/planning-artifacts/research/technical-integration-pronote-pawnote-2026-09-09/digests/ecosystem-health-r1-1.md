Release history shows at least 5 releases within the last 12 months (2025-09-03 through 2026-09-03), indicating an ongoing (if slow) release cadence. — Source: GitHub REST API, https://api.github.com/repos/bain3/pronotepy, https://api.github.com/repos/bain3/pronotepy/contributors, https://api.github.com/search/issues?q=repo:bain3/pronotepy+type:issue+state:closed, accessed 2026-09-09, confidence: high, class: ecosystem-signal

- The **original** "pronote-api" project (by Litarvan, github.com/Litarvan/pronote-api) — an earlier, language-agnostic unofficial Pronote API that predates both pronotepy and Pawnote — was discontinued on 2021-04-30 at the explicit request of Index Éducation (Pronote's publisher). The maintainer's own README ("Pronote API - Post-mortem") states: "A compter du 30 Avril 2021, le projet 'pronote-api' est malheureusement arrêté à la demande d'Index Éducation. Le dépôt GitHub a été vidé de son historique, et le paquet NPM supprimé," citing French law on unauthorized access to computer systems (STAD) as the legal basis for the takedown. — Source: Litarvan/pronote-api README (raw), https://raw.githubusercontent.com/Litarvan/pronote-api/master/README.md, accessed 2026-09-09, confidence: high, class: landscape

- Litarvan/pronote-api repo stats: 191 stargazers, last push (repo history wipe) recorded 2021-04-30T07:32:33Z, not marked "archived" at the GitHub API level but has had no commits since the 2021 takedown. This is a confirmed abandoned/legally-forced-shutdown project — a real precedent risk for any unofficial Pronote client. — Source: GitHub REST API, https://api.github.com/repos/Litarvan/pronote-api, accessed 2026-09-09, confidence: high, class: ecosystem-signal
